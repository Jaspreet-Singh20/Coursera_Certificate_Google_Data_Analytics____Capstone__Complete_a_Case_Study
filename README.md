# Google Data Analytics Capstone – Complete a Case Study

## 📊 Project Overview

This project is the **capstone project of the Google Data Analytics Professional Certificate**. It provides an opportunity to apply data analytics skills to a real-world business case study.

Throughout this project, I practiced the complete data analysis process, including:

* Asking relevant questions
* Preparing data
* Processing and cleaning data
* Analyzing data
* Visualizing findings
* Communicating insights
* Making data-driven decisions

The project demonstrates how data can be transformed into meaningful insights that can support business decision-making.

## 🎯 Objectives

The main objectives of this capstone project are to:

1. Define a real-world business problem.
2. Ask effective analytical questions.
3. Collect and prepare relevant data.
4. Clean and process the dataset.
5. Perform exploratory and descriptive analysis.
6. Identify patterns and trends.
7. Create meaningful data visualizations.
8. Communicate key findings and recommendations.
9. Present the results as a professional data analytics case study.

## 🔍 Data Analytics Process

The project follows the major stages of the data analytics workflow:

**Ask → Prepare → Process → Analyze → Share → Act**

### 1. Ask

Define the business problem and identify the questions that need to be answered.

### 2. Prepare

Identify, collect, and understand the data required for the analysis.

### 3. Process

Clean, organize, transform, and validate the data.

### 4. Analyze

Use analytical techniques to identify patterns, relationships, and trends.

### 5. Share

Present the findings using charts, visualizations, and clear explanations.

### 6. Act

Use the insights to develop data-driven recommendations and support decision-making.
